Learn C Programming

C is a powerful general-purpose programming language. It is fast, simple, and widely used in system programming, embedded systems, and software development. Let’s explore the basics of C for beginners.

1. Basic Structure of a C Program

Every C program has a structure that includes header files, main() function, and statements.

#include <stdio.h>

int main() {
    printf("Hello, World!");
    return 0;
}

2. Variables & Data Types

Variables store data. Common data types include int, float, char.

#include <stdio.h>

int main() {
    int age = 20;
    float pi = 3.14;
    char grade = 'A';

    printf("Age: %d, Pi: %.2f, Grade: %c", age, pi, grade);
    return 0;
}

3. Input & Output

We use printf() to display output and scanf() to take input.

#include <stdio.h>

int main() {
    int num;
    printf("Enter a number: ");
    scanf("%d", &num);
    printf("You entered: %d", num);
    return 0;
}

4. Operators

C supports arithmetic, relational, logical, and assignment operators.

#include <stdio.h>

int main() {
    int a = 10, b = 5;
    printf("Sum = %d", a + b);
    printf("\nComparison = %d", a > b);
    return 0;
}

5. Conditional Statements

Conditions control program flow using if, else, switch.

#include <stdio.h>

int main() {
    int num = 10;
    if(num > 0) {
        printf("Positive");
    } else {
        printf("Negative");
    }
    return 0;
}

6. Loops

Loops are used for repeating tasks: for, while, do-while.

#include <stdio.h>

int main() {
    for(int i=1; i<=5; i++) {
        printf("%d ", i);
    }
    return 0;
}

7. Functions

Functions divide code into reusable blocks.

#include <stdio.h>

void greet() {
    printf("Hello from function!");
}

int main() {
    greet();
    return 0;
}

8. Arrays

Arrays store multiple values of the same type.

#include <stdio.h>

int main() {
    int marks[3] = {90, 85, 78};
    for(int i=0; i<3; i++) {
        printf("%d ", marks[i]);
    }
    return 0;
}

9. Strings

Strings are arrays of characters ending with \0.

#include <stdio.h>

int main() {
    char name[20] = "EduTech";
    printf("Welcome %s", name);
    return 0;
}

10. Pointers

Pointers store memory addresses of variables.

#include <stdio.h>

int main() {
    int a = 10;
    int *ptr = &a;
    printf("Value: %d, Address: %p", *ptr, ptr);
    return 0;
}

By the end of this course, you’ll be able to write, compile, and run C programs with confidence.
