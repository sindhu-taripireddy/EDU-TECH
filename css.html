Learn CSS

CSS (Cascading Style Sheets) is used to style and design HTML elements. It controls layout, colors, fonts, spacing, and responsiveness of a webpage.

1. CSS Syntax & Selectors

CSS uses selectors to target HTML elements and apply styles.

p {
  color: blue;
  font-size: 16px;
}

#main {
  background: lightgray;
}

.container {
  padding: 20px;
}

2. Colors & Backgrounds

You can set colors using names, HEX, RGB, or HSL values.

body {
  background-color: #f4f4f4;
}

h1 {
  color: rgb(255, 0, 0);
}

div {
  background: url('image.jpg') no-repeat center center;
}

3. Fonts & Text Styling

CSS controls font family, size, weight, alignment, and decoration.

p {
  font-family: Arial, sans-serif;
  font-size: 18px;
  font-weight: bold;
  text-align: center;
  text-decoration: underline;
}

4. Box Model

The box model includes margin, border, padding, and content.

div {
  width: 200px;
  padding: 20px;
  border: 2px solid black;
  margin: 15px;
}

5. CSS Positioning

Elements can be positioned using static, relative, absolute, fixed, and sticky.

.box {
  position: absolute;
  top: 50px;
  left: 100px;
}

6. Flexbox Layout

Flexbox is used to align and distribute elements easily.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

7. CSS Grid

Grid layout is powerful for creating two-dimensional designs.

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

8. CSS Pseudo-classes & Pseudo-elements

They allow styling based on element states or adding extra elements.

a:hover {
  color: red;
}

p::first-line {
  font-weight: bold;
}

9. Transitions & Animations

CSS can add motion and effects.

button {
  transition: background 0.3s;
}

button:hover {
  background: blue;
  color: white;
}

@keyframes fade {
  from { opacity: 0; }
  to { opacity: 1; }
}

10. Responsive Design with Media Queries

Media queries adjust layout for different devices.

@media (max-width: 600px) {
  body {
    background: lightblue;
  }
}

By learning CSS, you’ll be able to design beautiful, responsive, and modern websites.
