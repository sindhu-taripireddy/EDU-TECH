CSS Basics Quiz

Test your knowledge of CSS fundamentals

Q1: What does CSS stand for?

✅ Correct! CSS means Cascading Style Sheets.
❌ Wrong! The answer is Cascading Style Sheets.

Q2: Which property changes text color?

✅ Yes! The property is color.
❌ Wrong. It’s color.

Q3: How do you select an element with id="demo"?

✅ Correct! Use #id for selecting elements.
❌ Wrong. It should be #demo.

Q4: Which property controls the size of text?

✅ Yes! font-size controls text size.
❌ Wrong. The correct answer is font-size.

Q5: Which property is used to change the background color?

✅ Correct! background-color sets background color.
❌ Wrong! It’s background-color.

Q6: Which is the correct CSS syntax to make all paragraphs bold?

✅ Right! Use font-weight: bold;
❌ Wrong. It’s font-weight: bold;

Q7: Which CSS property is used to change the font of an element?

✅ Correct! font-family changes the font.
❌ Wrong. The answer is font-family.

Q8: Which property adds space inside an element’s border?

✅ Yes! padding adds space inside borders.
❌ Wrong. It’s padding.
