Learn Python Programming

Python is a beginner-friendly, high-level programming language. It is widely used in web development, data science, artificial intelligence, and automation. Let’s explore the basics of Python for beginners.

1. Basic Structure of a Python Program

Python does not need special headers or main() by default. A simple print statement works:

print("Hello, World!")

2. Variables & Data Types

Variables in Python are dynamically typed. Common types include int, float, str, bool.

age = 20
pi = 3.14
name = "Alice"
is_student = True

print(age, pi, name, is_student)

3. Input & Output

We use print() for output and input() for input.

num = int(input("Enter a number: "))
print("You entered:", num)

4. Operators

Python supports arithmetic, relational, logical, and assignment operators.

a, b = 10, 5
print("Sum =", a + b)
print("Comparison:", a > b)

5. Conditional Statements

Conditions control program flow using if, elif, and else.

num = 10
if num > 0:
    print("Positive")
else:
    print("Negative")

6. Loops

Loops are used for repeating tasks: for and while.

for i in range(1, 6):
    print(i)

count = 1
while count <= 5:
    print(count)
    count += 1

7. Functions

Functions in Python are created using def.

def greet():
    print("Hello from function!")

greet()

8. Lists

Lists store multiple values and are flexible.

marks = [90, 85, 78]
for m in marks:
    print(m)

9. Strings

Strings are sequences of characters and support many operations.

name = "EduTech"
print("Welcome", name)
print("Length:", len(name))

10. Dictionaries

Dictionaries store data in key-value pairs.

student = {"name": "Alice", "age": 20, "grade": "A"}
print(student["name"])
print(student.get("grade"))

By the end of this course, you’ll be able to write Python programs and understand its core concepts.
