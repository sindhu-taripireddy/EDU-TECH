Learn HTML

HTML (HyperText Markup Language) is the standard language used to create and structure content on the web. It provides the foundation for all websites, defining the elements that browsers render.

1. HTML Structure & Elements

Every HTML page has a basic structure. It usually starts with <!DOCTYPE html>, followed by <html>, <head>, and <body> sections.

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>This is my first web page.</p>
  </body>
</html>

2. Forms & Input Tags

Forms collect user input. Common input types include text, email, password, and buttons.

<form>
  Name: <input type="text" name="name"><br>
  Email: <input type="email" name="email"><br>
  Password: <input type="password" name="pass"><br>
  <button type="submit">Submit</button>
</form>

3. Links & Navigation

Links are created using the <a> tag. They can point to internal or external pages.

<a href="https://www.google.com" target="_blank">Visit Google</a>

<nav>
  <a href="home.html">Home</a> |
  <a href="about.html">About</a> |
  <a href="contact.html">Contact</a>
</nav>

4. Tables & Lists

Tables organize data into rows and columns. Lists display items in order or as bullet points.

<table border="1">
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>22</td>
  </tr>
</table>

<ul>
  <li>Apples</li>
  <li>Bananas</li>
  <li>Cherries</li>
</ul>

5. Semantic HTML

Semantic elements describe their meaning to the browser and developers. Examples: <header>, <section>, <article>, <footer>.

<header>
  <h1>My Blog</h1>
</header>

<article>
  <h2>First Post</h2>
  <p>This is an article about HTML.</p>
</article>

<footer>
  <p>© 2025 My Website</p>
</footer>

6. Multimedia in HTML

HTML supports embedding images, audio, and video.

<img src="image.jpg" alt="A description" width="300">
<audio controls>
  <source src="sound.mp3" type="audio/mpeg">
</audio>
<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
</video>

7. Inline vs Block Elements

Block elements start on a new line (e.g., <div>, <p>), while inline elements don’t break the flow (e.g., <span>, <a>).

<div style="background:lightblue">Block Element</div>
<span style="color:red">Inline Element</span>

8. Forms with Dropdowns & Checkboxes

You can add checkboxes, radio buttons, and dropdowns for more complex forms.

<form>
  Choose fruit: 
  <select>
    <option>Apple</option>
    <option>Banana</option>
    <option>Cherry</option>
  </select><br>
  
  <input type="checkbox"> I agree to terms<br>
  <input type="radio" name="gender"> Male
  <input type="radio" name="gender"> Female
</form>

9. iFrames

iFrames allow embedding other web pages inside your page.

<iframe src="https://www.wikipedia.org" width="400" height="300"></iframe>

10. HTML5 APIs

HTML5 introduced powerful APIs like Geolocation, Local Storage, and Canvas.

<canvas id="myCanvas" width="200" height="100" style="border:1px solid #000"></canvas>

By the end of this course, you’ll be able to create a fully structured webpage and understand how HTML works in web development.
