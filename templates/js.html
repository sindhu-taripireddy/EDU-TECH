Learn JavaScript Programming

JavaScript is a beginner-friendly, versatile programming language. It is widely used in web development to make websites interactive. Let’s explore the basics of JavaScript for beginners.

1. Basic Structure of JavaScript

A simple script with console.log():

console.log("Hello, World!");

2. Variables & Data Types

Variables can be declared using var, let, or const. Common types include number, string, boolean, object.

let age = 20;
const pi = 3.14;
let name = "Alice";
let isStudent = true;

console.log(age, pi, name, isStudent);

3. Input & Output

We use alert(), prompt(), and console.log() in JavaScript.

let num = prompt("Enter a number:");
console.log("You entered:", num);

4. Operators

JavaScript supports arithmetic, relational, logical, and assignment operators.

let a = 10, b = 5;
console.log("Sum =", a + b);
console.log("Comparison:", a > b);

5. Conditional Statements

Conditions control flow using if, else if, and else.

let num = 10;
if (num > 0) {
    console.log("Positive");
} else {
    console.log("Negative");
}

6. Loops

Loops: for, while, and do...while.

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

let count = 1;
while (count <= 5) {
    console.log(count);
    count++;
}

7. Functions

Functions are created using function keyword.

function greet() {
    console.log("Hello from function!");
}

greet();

8. Arrays

Arrays store multiple values.

let marks = [90, 85, 78];
for (let m of marks) {
    console.log(m);
}

9. Strings

Strings support many operations.

let name = "EduTech";
console.log("Welcome " + name);
console.log("Length:", name.length);

10. Objects

Objects store data in key-value pairs.

let student = {name: "Alice", age: 20, grade: "A"};
console.log(student.name);
console.log(student.grade);

By the end of this course, you’ll be able to write JavaScript programs and understand its core concepts.
