HTML Basics Quiz

Test your knowledge of HTML fundamentals

Q1: What does HTML stand for?

✅ Correct! HTML means Hyper Text Markup Language.
❌ Wrong! Try again.

Q2: Which tag defines the largest heading?

✅ Yes! <h1> is the largest heading.
❌ Nope! The correct answer is <h1>.

Q3: Which tag inserts a line break?

✅ Correct! <br> adds a line break.
❌ Wrong! The correct is <br>.

Q4: Which tag is used to display an image?

✅ Right! <img> displays an image.
❌ Wrong. The correct is <img>.

Q5: Which attribute specifies a hyperlink destination?

✅ Correct! href specifies the destination URL.
❌ Nope. It’s href.

Q6: Which tag creates a numbered list?

✅ Yes! <ol> creates a numbered (ordered) list.
❌ Wrong. It’s <ol>.

Q7: Which tag is used to create a table row?

✅ Right! <tr> defines a table row.
❌ Wrong. The correct tag is <tr>.

Q8: Which tag is used for a form input field?

✅ Correct! <input> is used for form fields.
❌ Wrong. The correct answer is <input>.
